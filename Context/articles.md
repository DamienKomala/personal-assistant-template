# Reference Notes

**A scratch file for durable reference material** that doesn't belong in the profile, the criteria, or the ledger — market notes, salary research, an interview-prep framework worth reusing, a link to a hiring-process explainer.

⚠️ **Not skill input.** No skill reads this file by default. It exists so that useful research has somewhere to live other than a chat transcript.

⚠️ **If something here starts affecting decisions, promote it** — into `../Data/job-criteria.md` if it's policy, into `job-sources.md` if it's about senders, into the ledger if it's about a specific opportunity.
